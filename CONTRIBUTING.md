# Contributing Guidelines

Thank you for your interest in contributing to the Receipt OCR & Data Extraction API!

## Development Setup

1. Fork the repository
2. Clone your fork
3. Install dependencies:
   ```bash
   npm install
   cd backend && npm install
   cd ../frontend && npm install
   ```
4. Set up environment variables (see README.md)
5. Run database migrations
6. Start development servers

## Code Style

- Use TypeScript for all new code
- Follow existing code formatting
- Add comments for complex logic
- Write descriptive commit messages

## Testing

- Test file uploads with various image formats
- Verify OCR extraction accuracy
- Test error handling scenarios
- Check GraphQL queries and mutations

## Pull Request Process

1. Create a feature branch
2. Make your changes
3. Test thoroughly
4. Update documentation if needed
5. Submit a pull request with a clear description

## Areas for Contribution

- Improve OCR accuracy
- Add support for more receipt formats
- Enhance data extraction logic
- Add unit tests
- Improve error messages
- Add more filtering options
- Performance optimizations
